# QA WebApp 프로젝트 설명

## 프로젝트 개요
QA 파일 관리 웹 애플리케이션으로, 엑셀/CSV 파일을 업로드하고 HTML로 변환하여 편집 및 다운로드할 수 있는 시스템입니다.

## 프로젝트 구조

```
front/
├── src/
│   ├── App.js                 # 메인 애플리케이션 컴포넌트 (라우팅)
│   ├── index.js               # React 진입점
│   ├── components/            # 재사용 가능한 컴포넌트
│   │   ├── Layout.js          # 레이아웃 (사이드바 + 메인 콘텐츠)
│   │   ├── Sidebar.js         # 사이드바 네비게이션
│   │   ├── LocalFileUploader.js  # 파일 업로드 컴포넌트
│   │   ├── Modal.js           # 모달 다이얼로그
│   │   └── Notification.js   # 알림 메시지
│   ├── pages/                 # 페이지 컴포넌트
│   │   ├── QA.js              # QA 파일 목록 페이지
│   │   ├── QADetail.js        # QA 파일 상세 페이지 (편집 기능)
│   │   └── EmptyPage.js       # 빈 페이지 (플레이스홀더)
│   └── utils/                 # 유틸리티 함수
│       ├── api.js             # API 호출 함수
│       └── format.js          # 데이터 포맷팅 함수
```

## 애플리케이션 흐름도

```
[사용자]
    │
    ├─→ [시작] index.js
    │       │
    │       └─→ App.js (Router 설정)
    │               │
    │               ├─→ Layout.js
    │               │       │
    │               │       ├─→ Sidebar.js (네비게이션)
    │               │       └─→ [페이지 콘텐츠]
    │               │
    │               ├─→ /qa → QA.js
    │               │       │
    │               │       ├─→ 파일 목록 조회 (getQaFiles)
    │               │       ├─→ 파일 업로드 (uploadQaFile)
    │               │       └─→ 파일 삭제 (deleteQaFile)
    │               │
    │               └─→ /qa/files/:id → QADetail.js
    │                       │
    │                       ├─→ 파일 상세 조회 (getQaFileDetail)
    │                       ├─→ 피드백 저장 (saveQaFileFeedback)
    │                       ├─→ 테이블 편집 (로컬 상태 관리)
    │                       ├─→ 시트 저장 (saveQaFileSheets)
    │                       └─→ JSONL 변환/다운로드 (convertQaFileToJsonl)
    │
    └─→ [API 호출] api.js
            │
            └─→ [백엔드 서버] (http://localhost:8080/api)
```

## 주요 기능 흐름

### 1. 파일 업로드 및 목록 조회
```
사용자 → LocalFileUploader → uploadQaFile API → 백엔드
                                                    │
                                                    └─→ 파일 파싱 (엑셀 → HTML)
                                                    └─→ DB 저장
                                                    └─→ 응답 반환
                                            ↓
                                    QA.js에서 목록 새로고침
                                    getQaFiles API → 파일 목록 표시
```

### 2. 파일 상세 조회 및 편집
```
사용자 → QADetail.js
    │
    ├─→ getQaFileDetail API → 파일 정보 + 시트 HTML 조회
    │
    ├─→ 편집 모드 활성화
    │   ├─→ 셀 선택 (드래그)
    │   ├─→ 셀 병합
    │   ├─→ 셀 내용 편집 (contenteditable)
    │   └─→ Undo/Redo (히스토리 관리)
    │
    └─→ 저장
        ├─→ 피드백 저장 (saveQaFileFeedback)
        └─→ 시트 저장 (saveQaFileSheets)
```

### 3. JSONL 변환 및 다운로드
```
사용자 → "JSONL 변환" 버튼 클릭
    │
    ├─→ 각 시트별 HTML → 이미지 변환 (html2canvas)
    │   └─→ base64 인코딩
    │
    ├─→ convertQaFileToJsonl API 호출
    │   └─→ { fileName, sheets: [{ sheetName, htmlContent, imageBase64 }] }
    │
    └─→ 백엔드에서 JSONL 파일 생성
        └─→ 다운로드 (Blob)
```

## 추가로 만들면 좋은 것들

### 1. 인증 및 권한 관리
- **로그인/로그아웃 기능**
  - JWT 토큰 기반 인증
  - 사용자 세션 관리
  - 권한별 페이지 접근 제어

### 2. 에러 처리 강화
- **전역 에러 바운더리 (Error Boundary)**
  - 예상치 못한 에러 처리
  - 사용자 친화적인 에러 메시지
- **API 에러 재시도 로직**
  - 네트워크 오류 시 자동 재시도
  - 백오프 전략 적용

### 3. 성능 최적화
- **코드 스플리팅 (Code Splitting)**
  - React.lazy()를 사용한 라우트별 지연 로딩
  - 번들 크기 최적화
- **가상화 (Virtualization)**
  - 대용량 파일 목록 표시 시 react-window 사용
- **이미지 최적화**
  - JSONL 변환 시 이미지 압축
  - WebP 형식 지원

### 4. 사용자 경험 개선
- **로딩 상태 표시**
  - 스켈레톤 UI
  - 진행률 표시 (파일 업로드, 이미지 변환)
- **키보드 단축키**
  - Ctrl+S: 저장
  - Ctrl+O: 파일 열기
  - Esc: 모달 닫기
- **드래그 앤 드롭**
  - 파일을 직접 드래그하여 업로드
- **검색 및 필터링**
  - 파일명 검색
  - 날짜 범위 필터
  - 파일 타입별 필터

### 5. 테이블 편집 기능 강화
- **셀 병합 해제**
  - 병합된 셀을 원래대로 복원
- **행/열 추가/삭제**
  - 테이블 구조 편집
- **셀 스타일링**
  - 배경색, 텍스트 색상 변경
  - 텍스트 정렬 (좌/중/우)
- **복사/붙여넣기**
  - 셀 내용 복사 및 붙여넣기
  - 엑셀과 호환되는 형식

### 6. 데이터 관리
- **로컬 스토리지 백업**
  - 편집 중인 내용 자동 저장
  - 브라우저 새로고침 시 복원
- **버전 관리**

  - 이전 버전으로 되돌리기
- **내보내기 옵션 확장**
  - PDF 변환
  - 엑셀 형식으로 내보내기
  - CSV 변환

- **댓글 시스템**
  - 파일별 댓글 작성
  - @멘션 기능

  - 파일 공유 링크 생성

## 개발 시 주의사항

### 1. 상태 관리
- 현재는 로컬 상태(useState)를 주로 사용하고 있음
- 복잡도가 증가하면 Redux나 Zustand 같은 상태 관리 라이브러리 고려

### 2. API 호출 최적화
- 불필요한 API 호출 방지 (캐싱)
- Debounce/Throttle 적용 (검색 등)

### 3. 메모리 관리
- 대용량 파일 처리 시 메모리 누수 주의
- 이미지 변환 후 임시 요소 정리 확인

### 4. 브라우저 호환성
- 최신 브라우저 기능 사용 시 폴리필 고려
- 크로스 브라우저 테스트 필요

### 5. 보안
- 파일 업로드 시 파일 타입 검증 강화
- XSS 방지를 위한 입력값 검증
- API 키나 민감한 정보는 환경 변수로 관리
